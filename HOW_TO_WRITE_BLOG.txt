# 📝 BlockScript 新建文章指南
# 只要 3 步，超简单！

# ===== 第1步：新建文件夹 =====
# 在 blog/ 目录下新建一个文件夹，名字是文章 ID（数字）
# 例如：blog/99/

# ===== 第2步：放入解码器 =====
# 把 blog/_decoder/index.html 复制到你的文章文件夹
# 例如：blog/99/index.html

# ===== 第3步：写 .blog 文件 =====
# 在文章文件夹里新建一个文件：{id}.blog
# 例如：blog/99/99.blog
# 
# 文件内容格式如下（直接复制改内容即可）：


# ========== 复制下面内容开始写 ==========

[Title] 这里写文章标题
[Date] 2026-06-15
[Author] 管哥
[Tag] 标签1, 标签2

[正文开始]

[H1] 文章大标题

这里是正文第一段，直接写就行。
**加粗** 和 *斜体* 都支持。

[H2] 二级标题

- 列表项1
- 列表项2

[Code lang=python]
print("Hello World")
[/Code]

[Alert type=warning]
警告提示写这里
[/Alert]

全文完！

# ========== 复制上面内容结束 ==========


# ===== 高级：插入图片 =====
# 把图片放在文章文件夹里（和 index.html 同级）
# 然后在 .blog 文件里用 HTML 插入：
#
# [HTML]
# <img src="./my-image.png" style="max-width:100%;border-radius:8px;">
# [/HTML]


# ===== 预览文章 =====
# 双击 index.html 用浏览器打开
# 或者访问：http://localhost:xxxx/blog/99/index.html（需要本地服务器）


# ===== 已支持的语法 =====
# [H1] ~ [H3]      标题
# [ul] ... [/ul]    无序列表
# [ol] ... [/ol]    有序列表
# [quote] ... [/quote]  引用
# [Code lang=xxx] ... [/Code]  代码块
# [Alert type=xxx] ... [/Alert]  提示框
# [Btn href=xxx color=xxx] ... [/Btn]  按钮
# [Table] ... [/Table]  表格
# [HR]  分割线
# [HTML] ... [/HTML]  原始 HTML
# [Image src=xxx] ...  图片（新）
# [Video src=xxx] ...  视频（新）
# [Audio src=xxx] ...  音频（新）
# [PDF src=xxx] ...  PDF 文件（新）
# **文字**  加粗
# *文字*  斜体
# `代码`  行内代码
# [文字](链接)  链接

# ===== 高级：插入多媒体（新功能）=====
# 现在支持直接用标签插入图片、视频、音频、PDF，不需要写 HTML！

# --- 插入图片 ---
# [Image src=图片路径 alt=图片描述 width=宽度 caption=图片说明]
# 示例：
# [Image src=./screenshot.png alt=截图 width=80% caption=这是截图说明]

# --- 插入视频 ---
# [Video src=视频路径 width=宽度 controls=是否显示控制条 autoplay=是否自动播放 loop=是否循环 muted=是否静音]
# 示例：
# [Video src=./demo.mp4 width=100% controls=true]

# --- 插入音频 ---
# [Audio src=音频路径 controls=是否显示控制条 autoplay=是否自动播放 loop=是否循环]
# 示例：
# [Audio src=./music.mp3 controls=true]

# --- 插入 PDF ---
# [PDF src=PDF文件路径 width=宽度 height=高度]
# 示例：
# [PDF src=./document.pdf width=100% height=800px]

# 注意：这些标签都是"自闭合"的，不需要结束标签（不像 [Code]...[/Code] 那样）
# 文件要放在文章文件夹里（和 index.html 同级）
