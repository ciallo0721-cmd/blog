🎯 如何使用这个模板

方法1：作为参考

打开这个文件（muban.blog），查看各种语法的写法，然后照着写自己的文章。

方法2：复制改内容

1. 复制 muban.blog 为 你的文章ID.blog
2. 修改头部元数据（标题、日期、作者、标签）
3. 删除不需要的演示内容
4. 添加你自己的内容

方法3：从零开始

参考 HOW_TO_WRITE_BLOG.txt 和 BLOGSYNTAX.txt 文件，从零开始写。

💡 提示

⚠️ 注意事项：

1. 多媒体文件要放在文章文件夹里（和 index.html 同级）

2. 图片/视频/音频路径要写对（用 ./文件名 表示当前文件夹）

3. PDF 用 [PDF] 标签嵌入，需要浏览器支持 PDF 预览

4. 文件太大影响加载速度（建议压缩后再上传）

💡 快速测试：

1. 双击 index.html 用浏览器打开

2. 如果能看到这篇文章，说明解码器工作正常

3. 如果图片/视频/音频能播放，说明文件路径正确
