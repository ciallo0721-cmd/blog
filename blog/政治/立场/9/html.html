关于GitHub Issue被恶意篡改的说明

📅 2026-03-04
✍ ciallo0721-cmd
文章

致每一位可能看到这篇文章的人，尤其是从那个 Issue 过来的访客

如果你是因为在 GitHub 上看到一个名为 china-dictatorship的仓库(作者:cirosantilli)，点进了其中编号为 #1663 的 Issue，并被里面的一堆反华网址所困惑，那么请你花几分钟读完这篇文章。事情不是你看到的那样。

事件真相

2026年2月底，我在浏览 GitHub 时发现了上述仓库。该仓库名称及内容带有明显的针对中国的仇恨和歧视色彩。出于一个中国公民的朴素情感，我在该仓库的 Issues 区发布了一条批评内容（原话:我直接我拿那个灭火器，我********里面,司马反动派）。随后，该仓库的管理员（也就是那个作者）利用管理员权限，将我发布的 Issue 正文恶意篡改，塞入了一大堆反华网站链接，企图造成“这些链接是我发的”的假象。然而，他忽略了一点：GitHub 的每一次修改都会留下历史记录。同时，我在评论区留下的“孙笑川干的”等玩梗评论，他无法篡改。

我的立场

我，ciallo0721-cmd，坚决反对任何抹黑中国、分裂国家的言论和行为。我热爱我的祖国，拥护中国共产党的领导，坚持一个中国原则。台湾自古以来就是中国的神圣领土，不容置疑。 这也是我最初站出来批评那个仓库的原因。我的发声，是出于一个中国人的本能和责任感。

律师的意见

事件发生后，我曾一度陷入恐惧：害怕被误解、害怕网警上门、害怕留案底。我咨询了一位律师（免费咨询，也就是“0元取”），并将所有证据（修改历史截图、举报记录等）发给了他。律师看过之后明确告诉我：“没啥事，不用报警。你没有任何违法行为，那些链接是他改的，与你无关。” 律师的专业判断让我逐渐冷静下来。虽然咨询是免费的，但他的结论基于法律事实，是可信的。

给从那个 Issue 过来的人

如果你是因为那个被篡改的 Issue 而来到这里的，请你务必点击该 Issue 右上角的 “...”，选择 “View edits” 或查看修改历史。 你会清楚地看到：原始内容是我的批评，后来被管理员改成了网址。那些网址与我无关。我从未发布过任何反华、违法或不良信息。我的评论区依然保留着原话，可以作为旁证。

我的诉求与现状

我已经通过 GitHub 官方举报渠道和国家网信办举报中心（12377.cn）对该仓库进行了正式举报。目前，举报已受理，等待处理结果。我保留了一切证据，包括修改历史截图、举报记录以及与律师的沟通记录。法律上，我是完全清白的。

最后想说的话

网络不是法外之地，每个人都要为自己的言行负责。我为我最初的冲动言辞（骂人）道歉，但我的初衷是维护国家尊严。对于那些躲在屏幕后恶意篡改他人内容、企图嫁祸于人的人，我想说：你改得了文字，改不了历史；你骗得过一时，骗不过一世。真相或许会迟到，但永远不会缺席。

如果哪一天我没消息了，要么是被传去局子里了（当然这几乎不可能），要么是懒。但无论如何，这篇文章会一直在这里，作为最真实的记录。

“清者自清，浊者自浊。” 感谢每一位愿意了解真相的人。
