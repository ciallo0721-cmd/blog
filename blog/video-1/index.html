加密方式

  • AES-128 — 央视标准加密
  • 每个 .ts 分片独立加密
  • 密钥通过 #EXT-X-KEY 标签分发
  • 支持 METHOD=AES-128 / SAMPLE-AES

分片结构

  • 主播放列表：index.m3u8
  • 视频分片：segment_001.ts
  • 典型分片时长：2~10 秒
  • 多码率自适应：RESOLUTION=1920x1080

播放器

  • 自研 nice-video.js 播放器
  • hls.js 解码 HLS 流
  • 支持 .m3u8 / .ts 加密流
  • 粉色渐变 UI · 全屏 · 进度条 · 音量

📺 关于 HLS 加密流媒体

HLS (HTTP Live Streaming) 是 Apple 提出的流媒体协议， 被广泛应用于直播和点播场景。央视网、各大视频平台均使用 HLS + AES-128 加密方案。

加密流程：视频 → 分割为 .ts 分片 → AES-128 加密每个分片 → 生成 .m3u8 播放列表（含密钥信息）→ 客户端请求密钥并动态解密播放。

💡 提示：使用配套的 mp4_to_hls.bat 把视频转成 .ts/.m3u8 放到本目录， 浏览器会自动加载 ./1.m3u8 喵～
