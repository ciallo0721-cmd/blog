为什么要有这个收集帖？

网站上线以来，收到了不少朋友的留言和私信，有的说想要某个小工具，有的觉得某个页面太长了，还有的想让我删掉一些过时的内容。

我一个人想不全所有需求，所以干脆在 GitHub 仓库开了一个 专门收集建议的 Issue。你不需要懂代码，只要会写中文，就能直接评论。

我会每天看一遍，合理的、我能做到的，就会安排上。

去评论的链接

点击这里，去 GitHub Issue 评论
（没有 GitHub 账号也能看，但评论需要注册一个，几分钟就好）

你可以建议什么？

  • 新增东西：新页面、新文章、新游戏入口、实用小工具（计算器、倒计时、随机数等）
  • 修改内容：某段文字、布局、配色、字体大小、移动端适配
  • 删除内容：觉得哪个模块没用、碍眼、过时，直接说
  • 性能/体验：加载慢、特效太卡、验证流程烦人、音乐播放器不好用
  • Python 编辑器：想要更多库、更好用的输入、代码模板
  • 其他任何想法：你觉得"这里可以更好"的地方

提建议的小建议（非强制）

  • 说清楚 哪个页面、哪个位置（比如：首页「关于我的说～」那一块）
  • 如果可以，说一下 希望变成什么样（比如：文字折叠、加个按钮）
  • 一条评论说一个建议，方便我逐个处理
  • 可以带截图（直接把图片拖进 GitHub 评论框就行）

我不会做这些

  • 违法、政治敏感、色情、恶意攻击的内容
  • 会破坏网站基本安全的改动（比如完全去掉验证）
  • 需要我付费才能实现的功能（等以后有服务器再说）

我会怎么处理？

  • ✅ 每天统一看一遍所有新评论
  • ✅ 能立刻改的：我会回复「已处理」，然后去改代码
  • ✅ 需要时间的：我会回复「已收录，后续安排」
  • ✅ 做不了的：我会回复原因，不会无视你

举个例子

建议：首页「关于我的说～」那一块文字太多了，手机上滑很久才到游戏预览。
位置：index.html 的 #about 区域
希望：加一个「阅读更多」折叠按钮

我会回复：收到，下周加上折叠功能。

没有 GitHub 账号怎么办？

注册一个 GitHub 账号是免费的，只需要邮箱，两三分钟就能搞定。如果你实在不想注册，也可以在这个文章下面留言（但文章评论区还没做……所以还是推荐用 GitHub）。

或者直接通过 B站 / 抖音 私信我，我也会定期整理。
