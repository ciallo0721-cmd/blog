## 一、6W1H 分析框架

| 维度 | 内容 | 说明 |
|:---:|------|------|
| **WHO** 谁 | 独立游戏玩家、二次元文化爱好者、视觉小说玩家、Python学习者、B站用户 | 主用户画像：15-25岁，熟悉B站/QQ空间，愿意尝试新事物的年轻人 |
| **WHEN** 何时 | 晚间20:00-23:00（游戏高峰期）；午休12:00-14:00（摸鱼时段）；周末全天 | B站视频/动态引流后的30分钟内是黄金转化期 |
| **WHERE** 何地 | B站视频评论区、B站动态、QQ群（游戏/VN同好群）、CSDN/博客园技术社区、百度/Google搜索 | 核心战场：B站；次级：搜索引擎 + 技术社区 |

## 二、AISCEAS 消费者决策路径

### 🔥 Attention 引起注意（0-3秒）
| 策略 | 具体动作 |
|------|---------|
| **B站封面爆点** | 视觉冲击封面：游戏截图+大字「泪崩」「烧脑」「甜到发腻」等情绪词 |
| **搜索引擎摘要** | meta description 含「视觉小说」「Python编辑器」「免费」「在线」等关键词 |
| **社交媒体卡片** | 链接预览卡片显示高饱和渐变 + 游戏截图，形成视觉反差 |

### 🔥 Interest 激发兴趣（3-15秒）
| 策略 | 具体动作 |
|------|---------|
| **开场即游戏** | 验证流程结束后第一屏直接展示游戏预览区，降低进入门槛 |
| **Python编辑器** | 零门槛在线运行Python，制造「哇，我也能写代码」的惊喜感 |
| **简介文案** | 「代码能写出什么？这里有答案」——用问句引发好奇心 |
| **彩虹动画标题** | 四色渐变标题栏持续动效，形成视觉记忆点 |

### 🔥 Search 主动搜索（用户离开后）
| 策略 | 具体动作 |
|------|---------|
| **SEO关键词** | 布局「Ren'Py视觉小说」「Python在线编辑器」「二次元游戏」等长尾词 |
| **B站视频标题** | 含搜索友好词：「教程」「实况」「自制」「完整版」 |
| **sitemap.xml** | 确保所有页面被Google/百度索引 |

### 🔥 Comparison 对比考量（用户在犹豫）
| 策略 | 具体动作 |
|------|---------|
| **差异化定位** | 强调「免费 + 无需安装 + 浏览器直接玩」的零门槛优势 |
| **B站对比视频** | 投稿「我做了个游戏/工具网站，对比市面同类产品」 |
| **评论区互动** | 及时回复，建立信任感，减少用户疑虑 |

### 🔥 Examination 深度体验（5-30分钟）
| 策略 | 具体动作 |
|------|---------|
| **游戏完整试玩** | 提供完整版游戏（非demo），让用户沉浸体验 |
| **Python编辑器** | 预设示例代码（图形绘制/小游戏），引导用户修改运行 |
| **技术文章** | 深度内容展示开发者实力，建立专业信任 |
| **网站状态透明** | status.html展示各页面健康状态，传递「认真运营」信号 |

### 🔥 Action 促成行动（转化）
| 策略 | 具体动作 |
|------|---------|
| **明确CTA按钮** | 每个游戏卡片「在新标签页打开」，每个文章「阅读全文」 |
| **分享引导文案** | 页面底部：「喜欢这里？快分享给朋友！」 |
| **B站视频CTA** | 视频结尾：「视频简介有链接，点进去看看」 |
| **邮件/留言** | 预留联系方式，收集用户反馈 |

### 🔥 Share 口碑传播（裂变）
| 策略 | 具体动作 |
|------|---------|
| **分享激励文案** | 「看完记得分享——也许你朋友正在找这个！」 |
| **一键复制链接** | 分享按钮一键复制网址，降低分享摩擦 |
| **B站评论区** | 引导：「觉得不错的话，投个币/转发支持一下」 |
| **内容再生产** | 提供高质量截图/素材，方便用户二创传播 |

## 四、PEST × 3C × 5F × SWOT 四维战略矩阵

### PEST 宏观环境分析

| 维度 | 机会 Opportunity | 风险 Risk |
|------|-----------------|-----------|
| **P 政治/政策** | 国家鼓励游戏产业精品化；编程教育纳入课标 | 未成年人游戏监管趋严（但受众偏成年向） |
| **E 经济** | 独立游戏市场增长；用户愿为优质内容付费 | 经济下行时娱乐预算压缩 |
| **S 社会** | 二次元文化主流化；Z世代创作欲强 | 同类竞品多，用户注意力碎片化 |
| **T 技术** | GitHub Pages免费托管；Ren'Py引擎成熟；AI辅助开发降低门槛 | 大厂3A品质竞争；技术迭代快 |

### 3C 分析（Company · Competitor · Customer）

| 维度 | 分析 |
|------|------|
| **Company（自身）** | 优势：独特视觉风格、零门槛Python编辑器、原创游戏内容；劣势：流量基础薄弱、更新频率不稳定、个人运营时间有限 |
| **Competitor（竞品）** | 国内：灰犀牛游戏、Notion类工具站；B站技术UP主（Python教学类）；国外：itch.io独立游戏平台。竞品优势：流量大、品类全；劣势：不专注、体验重 |
| **Customer（用户）** | 需求：免费好玩的内容、零门槛工具、情感共鸣的故事；顾虑：不知道网站在哪、质量是否有保障 |

### 5F 五力分析

| 力 | 强度 | 对策 |
|----|------|------|
| **现有竞争者** | 🟡 中（B站/独立游戏站） | 差异化：垂直细分（视觉小说+Python工具） |
| **新进入者威胁** | 🟡 中（技术门槛低） | 持续产出原创内容，建立品牌认知 |
| **替代品威胁** | 🟡 中（大型游戏/在线课程） | 强调「轻量」「免费」「即开即用」 |
| **供应商议价能力** | 🟢 低（技术栈免费） | 继续使用开源工具，保持零成本 |
| **买家议价能力** | 🟢 低（用户免费使用） | 持续提供价值，维持用户粘性 |

### SWOT 矩阵

|  | **有利** | **不利** |
|--|---------|---------|
| **内部** | **S优势**：原创视觉小说内容、在线Python编辑器零门槛、B站粉丝基础、二次元风格鲜明 | **W劣势**：流量基数小、内容更新不稳定、初中身份（已隐藏）、无商业变现 |
| **外部** | **O机会**：二次元市场增长、AI降低开发门槛、B站流量红利、GitHub Pages零成本托管 | **T威胁**：大厂精品竞争、竞品模仿、政策监管不确定性 |
