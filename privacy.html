一、本站收集什么

为了在收到 Bug 反馈、处理争议或内容被转载时能够追溯来源，本站会在您的浏览器中生成并使用以下信息：

项目内容存储位置可逆性
用户标识 userid随机生成的访客编号浏览器 localStorage不含个人身份信息
操作系统版本如 Windows 11 / macOS 15仅出现在水印中不可逆
IP 哈希公网 IP 经第三方接口查询后 SHA-256 加盐哈希仅出现在水印中不可逆

说明：本站通过第三方接口 api.ip.sb 查询访客公网 IP，仅用于生成不可逆哈希（加固定盐后取前 12 位十六进制）。哈希无法还原为真实 IP，无法定位到具体地址；IP 本身不会被存储、不会对外公开、不会出售。接口不可用时自动降级为内网 IP 哈希或占位符。哈希仅用于区分不同访客、处理 Bug 反馈与内容溯源。

二、userid 生成规则

每位访客首次访问时自动生成一个唯一编号，格式为：

cialloblog-{系统}-{随机4位}-{年份}

其中「系统」部分的编码规则如下：

系统编码示例
Windows 1111cialloblog-11-3f2a-2026
Windows 1010cialloblog-10-8c1d-2026
Windows 7（个位数补零）07cialloblog-07-a91c-2026
Windows 9898cialloblog-98-5b2e-2026
仅能识别 NT 版本nt-版本cialloblog-nt-10.0-77d0-2026
macOSmc-版本cialloblog-mc-15-1c4f-2026
Linuxlx-发行版cialloblog-lx-ubuntu-9e07-2026
Android / iOSad-版本 / io-版本cialloblog-ad-14-42ab-2026
无法识别ot-xxxxcialloblog-ot-xxxx-3d81-2026

随机 4 位由浏览器加密级随机数生成器产生，每次访问不改变；仅当您清除浏览器数据后才会重新分配。

三、隐形水印

本站页面会叠加一层肉眼几乎不可见的透明水印，内容包含您的 userid、系统编码与 IP 哈希。它不影响浏览、不遮挡内容、不收集额外数据。

  • 用途：当您截图反馈 Bug 时，站长可通过截图中的水印定位到对应的 userid，快速确认问题环境；当内容被截图转发时，同样用于溯源。
  • 透明度：约 3.5%，正常浏览完全不可见。
  • 不会公开：水印信息仅站长本人可见，不会展示在页面上，不会写入任何公开内容。

请勿使用截图分享本站内容时携带的个人信息进行骚扰或人肉搜索——本站不会、也不支持任何形式的网络暴力行为。

四、如何清除这些数据

  • 清除浏览器站点数据（Cookie 与网站数据）后，userid 即被删除，下次访问会生成新的编号；
  • 使用浏览器的「无痕 / 隐私模式」访问，则每次会话都会生成临时编号；
  • 水印随页面渲染产生，关闭页面即消失，不会在您的设备上留下任何文件。
