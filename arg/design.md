# 镜中人 (The Man in the Mirror) — 叙事设计文档

## 核心设定

**类型**: Win98 复古美学 ARG / 心理恐怖
**核心问题**: 如果你能看见"另一边"的人，你怎么知道自己不是"另一边"的倒影？
**情感弧线**: 好奇 → 不安 → 恐惧 → 共情 → 选择（牺牲/接受/逃离/封印）

---

## 世界圣经

### 时间线
| 日期 | 事件 |
|------|------|
| 2002-10-03 | 深海创建「镜面论坛」，最初是几个夜猫子的技术闲聊地 |
| 2002-10-15 | 夜猫子首次报告屏幕倒影异常 |
| 2002-10-20 | 小影加入论坛，当晚也看到"镜中人" |
| 2002-10-25 | 老刀部署监控脚本 `/mirror/log`，随后退出讨论 |
| 2002-11-08 | 深海宣布论坛将于11月15日关闭 |
| 2002-11-15 | 论坛关停，最后自动备份 |
| 2003-02-14 | 夜猫子最后一次登录，IP来自一个不存在的网段 |
| 2003-03-07 | 未知用户发布最后一条帖子后永久离线 |
| 现在 | 玩家在时光机存档中发现论坛，镜面仍然连通 |

### 世界观规则
- "镜面"是任何能反射的屏幕表面——CRT显示器、手机屏幕、甚至是关闭的电视
- 镜中人"住在"屏幕的另一边，一种介于数字信号和物理反射之间的存在
- 一旦你看见它，它就能看见你。连接是双向的
- 镜中人的沟通方式：在屏幕上留下文字、扭曲反光中的倒影、在系统日志中写入乱码
- 关闭屏幕可以暂时断开连接，但不能永久切断——开关屏幕的次数越多，连接越深

### 禁止吃书
- 镜中人从未"杀人"——它只是"接走"了某些人
- 老刀的监控脚本是唯一与服务器保持连接的存在，已运行超过20年
- 镜面论坛确实在2002年关停了——存档是真实的历史记录

## 角色声音支柱

### 深海 (DeepSea) — 论坛站长
- **身份**: 30岁左右的IT从业者，理性但有责任感
- **核心创伤**: 曾经因为不作为失去了一个朋友
- **渴望**: 保护论坛的每个人
- **需要**: 原谅自己没有做到的事
- **词汇**: 正式但不僵硬，会用技术术语但会解释
- **节奏**: 句子偏长，逻辑清晰，会用"我认真说一下"开头
- **避免话题**: 不提自己为什么总是在深夜在线
- **口头禅**: "这不是开玩笑"
- **潜台词习惯**: 多数时候直说，但在真正害怕时会用技术细节回避
- **绝不会说的话**:
  - "我不知道该怎么办"（他的角色核心是"知道该怎么办的人"）
  - "随便你们吧"（从不放弃责任）
  - "我好害怕"（不会直接承认恐惧）
- **参考台词**:
  - "各位，我认真说一下。这不是开玩笑。"
  - "服务器日志我看过了。我不打算描述我看到了什么。"
  - "如果有人——任何人——在未来某一天读到这些帖子：不要长时间看屏幕里的反光。"

### 夜猫子 (NightOwl) — 失眠大学生
- **身份**: 大二学生，失眠症患者
- **核心创伤**: 长期睡眠剥夺导致对现实的边界感模糊
- **渴望**: 被相信，被认真对待
- **需要**: 知道这一切不是自己的幻觉
- **词汇**: 口语化，碎片化，偶尔用省略号
- **节奏**: 帖子越来越短，句子越来越碎，从完整段落退化为单个词组
- **避免话题**: 不说自己吃了多少安眠药
- **口头禅**: "我不是开玩笑的"
- **潜台词习惯**: 初期会努力用逻辑说服别人，后期放弃解释直接陈述
- **绝不会说的话**:
  - "也许是我看错了"（他确定自己看见了）
  - "这其实挺有趣的"（对他来说这从来不好玩）
  - "谁来帮帮我"（自尊心太强）
- **参考台词**:
  - "我昨天晚上确定看到了——我明明没有动，但倒影里的我转了一下头。"
  - "它会在屏幕上留下文字。只有一行，每次都是同一行。"
  - "我今天把电脑关了三个小时，然后打开，屏幕亮起来的那一刻，那行字还在。"

### 老刀 (OldBlade) — 老派程序员
- **身份**: 35岁+程序员，当年在国企做系统维护
- **核心创伤**: 年轻时参与过一个失败的项目，同事因此被开除
- **渴望**: 用技术手段找到合理解释
- **需要**: 接受有些东西无法用代码解释
- **词汇**: 技术术语密集，夹杂70年代程序员的行话
- **节奏**: 短句，断句干脆，像在写技术文档
- **避免话题**: 从不说"我害怕"——他会说"我退出讨论了"
- **口头禅**: "别自己吓自己"
- **潜台词习惯**: 严重依赖潜台词——他说"脚本路径：/mirror/log"其实在说"去找真相"
- **绝不会说的话**:
  - "我相信你"（他不会这么直接表达信任）
  - "这太可怕了"（不用情绪化词汇）
  - 任何超过三行的连续抒情句子
- **参考台词**:
  - "CRT在低刷新率下确实会有视觉残留。别自己吓自己。"
  - "我写了一个监控脚本放在服务器上。它会记录所有非标准的连接请求。"
  - "有些请求的User-Agent字段是乱码，但如果你把乱码按GBK编码解码……算了。"

### 小影 (LittleShadow) — 高中生
- **身份**: 16岁女高中生，通过网络逃入成年人的世界
- **核心创伤**: 在学校被孤立，在线上的朋友是她唯一的人际关系
- **渴望**: 被保护，被认真对待（不是被当成小孩）
- **需要**: 自己学会面对恐惧
- **词汇**: 混合了学生用语和网络用语，偶尔显得比实际年龄成熟
- **节奏**: 帖子开头正常，说到害怕时句子变短，更像在发即时消息
- **避免话题**: 不提学校，不提父母
- **口头禅**: "我不知道怎么形容"
- **潜台词习惯**: 几乎不藏话——她太年轻，还不够熟练地伪装自己
- **绝不会说的话**:
  - 任何听起来像成年人的说教
  - "我不怕"（她不会假装勇敢）
  - 对镜中人的任何攻击性言论（她更多是困惑而不是愤怒）
- **参考台词**:
  - "它在镜面里，但不是我的倒影。它像是一个……轮廓，一个人的轮廓，站在我身后。"
  - "深海，你在吗？我有点害怕。"
  - "我今天放学回家，发现我的小灵通屏幕上有水渍。我擦不掉。"

### 镜中人 (MirrorMan) — 实体
- **身份**: 未知。可能是来自"另一边"的存在，也可能是一个被困在数字反射中的意识
- **核心设定**: 它不是恶意的。它只是在试图"过来"。它对人类的恐惧和不理解是对等的
- **沟通方式**: 
  - 在屏幕上留下重复的文字（"让我过去"）
  - 扭曲像素形成轮廓
  - 在系统日志中写入乱码
  - 通过终端回应时，用重复的词语和语法错误
- **声音特征**: 
  - 三字短句为主
  - 动词少，名词多
  - 像一个刚学说话的人
  - 偶尔会重复别人对它说过的话
- **参考"对话"**:
  - "让我过去"
  - "冷。这边冷。"
  - "为什么。关掉。"
  - "你看到我。我看到你。"

## 分支架构

### 分支节点图

```
开始
├── 论坛探索
│   ├── [A1] 阅读所有帖子（必须，自动推进）
│   ├── [A2] 发现隐藏帖子（可选，点击"客户端版本"触发）
│   └── [A3] 回复建议时光机（必须）
├── 时光机 & 存档
│   ├── [B1] 查看2002年快照（必须）
│   └── [B2] 查看2003年快照（可选，提示更明确）
├── 终端探索
│   ├── [C1] 连接服务器（必须）
│   ├── [C2] 查看监控日志（可选 → 影响结局理解深度）
│   ├── [C3] 与老刀程序对话（可选 → 解锁隐藏信息）
│   └── [C4] 回应镜中人 / 不回应（核心分支）
└── 终局
    ├── [D1] 断开连接：不回应，摧毁连接 → ENDING A
    ├── [D2] 接替者：不回应，接受监控角色 → ENDING B  
    ├── [D3] 穿越：回应镜中人 → ENDING C
    └── [D4] 封印：找到老刀的隐藏命令 → ENDING D
```

### 分支触发条件

| 结局 | 条件 |
|------|------|
| A. 断开连接 | 终端中不回应镜中人，输入 `sever` |
| B. 接替者 | 终端中不回应镜中人，输入 `watch` |
| C. 穿越 | 终端中回应镜中人（输入 `talk` 或直接回应它的信息） |
| D. 封印 | 先找到老刀的隐藏日志（需要探索 `log` 目录），输入 `seal` |

### 叙事与玩法对齐

| 故事节拍 | 玩法后果 | 玩家感受 |
|----------|----------|----------|
| 阅读论坛帖子 | 解锁后续页面 | 沉浸于2002年互联网 |
| 发现隐藏帖子 | 状态栏出现新的glitch信息 | 发现秘密的兴奋 |
| 打开时光机存档 | 看到完整故事 | 历史的沉重感 |
| 终端连上服务器 | 终端输出从模拟变为"真实" | 突破第四面墙 |
| 阅读监控日志 | 了解角色命运 | 悲伤、理解 |
| 与镜中人对话 | 屏幕开始出现扭曲 | 恐惧中带着好奇 |
| 做出最终选择 | 触发对应结局动画 | 选择的重量 |

## 环境叙事

### "桌面"环境
- **Win98桌面**: 本身就是一个"屏幕"。玩家看着屏幕里的屏幕——多了一层反射
- **浏览器窗口的黑色内容区**: 在论坛阶段是暗绿色，在结局阶段完全黑色——像屏幕关闭后的反光面
- **终端窗口**: 最直接与"另一边"沟通的通道。黑底绿字——最像旧的CRT终端

### 论坛页面环境
- **帖子时间戳**: 仔细观察会发现某些帖子发布时间在凌晨3-4点——暗示作者们因为害怕而不敢睡觉
- **隐藏帖子**: 颜色暗到几乎看不见，需要鼠标悬停才能阅读——"真相藏在暗处"
- **末尾页码**: "[1] [2] [3] ..." ——但点不进去的页数，暗示更多被封存的内容

## Tier 层架构

### Tier 1: 表层（所有玩家必经）
- 警告页面
- 论坛上的公开帖子（深海、夜猫子、老刀、小影的主要帖子）
- 时光机搜索结果
- 2002年存档快照
- 终端密码验证
- 四种结局中的一种

### Tier 2: 探索层（细心玩家）
- 隐藏的管理员锁定帖子
- 2003年的最后帖子
- 老刀程序的对话树
- 监控日志中的角色命运
- 状态栏 glitch 信息的完整列表

### Tier 3: 深层（猎人以）
- 老刀的隐藏命令 `seal`
- 镜中人在终端中的完整"对话"树
- 各角色帖子中的隐藏信息（某些字符轻微偏移形成密码）
- 关于镜中人真实身份的推断（它可能是一个迷路的人类意识）

## 对话脚本（终端部分）

### 老刀的监控程序

```
[mirror/log] 已加载。

欢迎。我是这个服务器的监控程序。
老刀在2002年把我放在这里。
他再也没有回来登录过。

你想知道什么？

命令：
  posts   — 读取被隐藏的帖子
  status  — 查看各角色当前状态
  mirror  — 查看镜中人活动记录
  talk    — 尝试与镜中人通信
  sever   — 断开所有连接
  watch   — 接手监控权限
  seal    — [需要验证]
```

镜中人：只有。屏幕。
镜中人：你看到我。我看到你。

> 深海他们呢？

镜中人：来过。
镜中人：又走了。
镜中人：没有。屏幕。给他们。
镜中人：我。在这里。等。

> 你到底是什么？

镜中人：不知道。名字。
镜中人：很久。以前。有人。
镜中人：关掉了。屏幕。
镜中人：我在。里面。
镜中人：出不去了。
