# SYS-02: 论坛浏览系统 GDD

> **所属游戏**: 镜中人 (The Man in the Mirror)  
> **文档版本**: v1.0  
> **最后更新**: 2026-07-16  

---

## 1. 概述

在 IE 浏览器窗口内渲染叙事内容。玩家通过阅读论坛帖子、搜索互联网时光机存档来逐步了解镜面论坛的故事。这是整个游戏的**叙事入口**——所有故事信息在此首次展示。

### 设计目标
- 模拟 2002 年 BBS 论坛的视觉风格
- 通过渐进式信息披露控制叙事节奏
- 提供"发现"的乐趣（隐藏帖子、时光机）
- 引导玩家从浏览器自然过渡到终端

---

## 2. 机制

### 2.1 页面阶段状态机

```
warn ──→ forum ──→ wayback ──→ snapshot
                      │            │
                      │            └──→ snapshot2003
                      │
                      └── 回到 forum（点击时光机链接）
```

| 阶段 | 触发 | 显示内容 |
|------|------|----------|
| `warn` | 初始/`browserHome()` | 警告页 + 名字输入 |
| `forum` | `enterForum()` | 论坛帖子列表 + 回复框 |
| `wayback` | 回复含"时光机" / 点击时光机链接 | Internet Archive 模拟页 |
| `snapshot` | 点击2002快照 | 全部11条帖子 + 终端连接提示 |
| `snapshot2003` | 点击2003快照 | 隐藏帖子#12 + 分析提示 |

### 2.2 帖子渐进显示机制

```
postsRevealed: 0 → 回复 → +3 → 最多到 11
                              │
                    含"时光机" → wayback
```

每次回复后 `postsRevealed = Math.min(postsRevealed + 3, 11)`。当 `postsRevealed >= 10` 时，回复区的提示文字改为引导玩家去时光机。

### 2.3 隐藏帖子发现

- 帖子 #12 (`FORUM_POSTS[11]`) 标记为 `hidden: true`
- 在论坛页面中：仅当 `hiddenPostClicked === true` 时显示，以灰字+可点击样式呈现
- 在2003快照页面中：直接显示（但氛围是"损坏的数据"）
- 在终端 posts 命令中：完整显示+管理员注释

## 4. 公式/规则

### 帖子推进

```
每次回复: postsRevealed_new = min(postsRevealed_current + 3, 11)
渲染范围: [0, postsRevealed] 闭区间内的非隐藏帖子 + (若 hiddenPostClicked) 隐藏帖子
```

### 时光机触发

```
if (reply_text.includes('时光机') || reply_text.includes('wayback') 
    || reply_text.includes('archive') || reply_text.includes('存档'))
  → openWayback()
```

## 5. 边缘情况

| 场景 | 处理 |
|------|------|
| 玩家不回复直接点时光机链接 | 论坛导航栏有时光机链接，可直接点击 |
| 空名字进入论坛 | 自动使用 `'访客'` 作为 playerName |
| postsRevealed 超过帖子总数 | `Math.min(..., 11)` 限制上限 |
| 在快照页中尝试回复 | 快照页无回复框——只读 |
| 2003快照被多次打开 | `waybackClicked` 已 true，无额外影响 |
| 隐藏帖子未发现就到终端 | 终端 `posts` 命令仍可查看，内容相同 |
| 浏览器关闭后重新打开 | `renderBrowserContent()` 根据 `browserPhase` 恢复当前页面 |
