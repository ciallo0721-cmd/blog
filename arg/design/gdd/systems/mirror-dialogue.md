# SYS-05: 镜中人对话系统 GDD

> **所属游戏**: 镜中人 (The Man in the Mirror)  
> **文档版本**: v1.0  
> **最后更新**: 2026-07-16  

---

## 1. 概述

管理玩家与"镜中人"实体之间的终端对话。这是一个4轮对话树，每轮镜中人以三字短句风格回应，最终导向结局C（穿越）。对话系统是游戏情感弧线从"恐惧"转向"共情"的关键转折点。

### 设计目标
- 镜中人的"声音"始终如一：三字短句、动词少名词多、像刚学说话
- 每轮对话揭示更多信息——关于镜中人自身、关于四个角色、关于选择
- 最后给出终极选择（"你过来"还是"让我过去"）
- 玩家在对话中感受到镜中人的孤独和困境——不是怪物，是同类

---

## 2. 机制

### 2.1 对话状态机

```
mirrorRound: 0 ──(talk命令)──→ 1 ──(任意输入)──→ 2 ──(任意输入)──→ 3 ──(任意输入)──→ 4 ──(任意输入)──→ ENDING C
```

- 进入条件：终端已连接 + 输入 `talk`
- 推进条件：任意键盘输入（不解析具体内容——任何回应都被镜中人视为"你在听"）
- 退出条件：对话完成后自动触发结局C
- 锁定机制：`mirrorRound` 在1-4之间时，所有终端命令输入都被重定向到 `advanceMirrorDialogue()`

### 2.2 对话设计原则

> **镜中人的沟通逻辑**：它不是在回答问题，而是在陈述自己的感受。玩家的输入只是"你在听"的信号——镜中人需要的是被听见，不是被回答。

| 原则 | 说明 |
|------|------|
| 不解析玩家输入 | 无论玩家打什么，对话都推进——降低实现复杂度，同时强调镜中人的"不可对话性" |
| 渐进信息释放 | 第1轮：自我介绍 → 第2轮：困境 → 第3轮：四个角色 → 第4轮：终极选择 |
| 三字短句 | "这。边。冷。"——标点制造停顿，暗示非人类沟通方式 |
| 重复模式 | 镜中人会重复之前听过的短语（"你看到我。我看到你。"） |

## 4. 公式/规则

### 对话流程控制

```
IF terminalPhase !== 'connected' → talk命令不可用
IF mirrorRound === 0 && cmd === 'talk' → mirrorRound = 1, 显示第1轮
IF mirrorRound IN [1,2,3] && any_input → mirrorRound++, 显示对应轮次
IF mirrorRound === 4 && any_input → triggerEnding('C')
```

### 对话期间命令劫持

```javascript
// terminalKeydown 中:
if (GAME_STATE.mirrorRound > 0 && GAME_STATE.mirrorRound < 5) {
  advanceMirrorDialogue();
  return;  // 阻止所有其他命令处理
}
```

## 5. 边缘情况

| 场景 | 处理 |
|------|------|
| 对话中输入命令关键词（如 `sever`） | 被劫持，仅推进对话——避免玩家在对话中"意外"触发结局 |
| 对话中输入空内容 | `terminalKeydown` 在 `!raw` 时 return，不推进对话 |
| 对话中关闭终端再打开 | `renderTerminal()` 检查 `endingTriggered`，若无则通过 `_savedTerminalHTML` 恢复对话状态 |
| 对话中触发刷新 | 全部状态丢失——这是设计意图（重来） |
| 已完成对话但未到第5轮 | 不可能——第4轮后自动触发结局C |
| 多周目中再次对话 | 当前无变化；建议二周目时对话有变化（见 C6） |

## 6. UI 接口

### 对话视觉风格

- 使用 `.terminal-mirror` 样式类：暗红色 (#c0392b) + 斜体
- 与系统输出（绿色）和状态信息（橙色）形成视觉区分
- 对话之间有 `---` 分隔线
- 底部显示操作提示（灰色小字）

### 对话渲染示例

```
C:\mirror>talk

[建立通信通道……]
[警告：你正在尝试与镜中人建立双向通信]

镜中人：你。
镜中人：看到我。
镜中人：跟。他们。一样。
---
（继续输入任何内容来与镜中人对话）

C:\mirror>_
```
