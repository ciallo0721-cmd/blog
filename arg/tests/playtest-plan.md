## 1. 测试前置准备

### 每轮测试前操作

```javascript
// 清除 localStorage 避免跨会话污染
localStorage.removeItem('mirror_completed_endings');
```

在 Chrome DevTools → Application → Local Storage → `https://ciallo0721-cmd.github.io` 中执行。

### 测试环境

- 浏览器: Chrome (推荐) / Edge
- 分辨率: 1440 × 900
- DevTools 开启 Console 面板（监控 JS 错误）

| 步骤 | 操作 | 预期结果 | 实际结果 | PASS/FAIL |
|------|------|----------|----------|-----------|

| D-02 | 回复推进 → 时光机 → 2002 快照 | 快照页 | | |
| D-03 | 打开终端，输入 `connect mirror-forum.bbs` | 连接成功 | | |
| D-04 | 输入 `posts`，回车 | 显示隐藏帖子 #12（夜猫子最后帖子），`postsRead = true` | | |
| D-05 | 输入 `seal`，回车 | 显示老刀最后信息 + "输入 confirm 确认执行"​ | | |
| D-06 | 输入 `confirm`，回车 | 触发结局 D：终端显示"老刀的隐藏协议已激活。…"，2 秒后 overlay | | |

### seal 命令的边界验证

| 检查项 | 操作 | 预期 | 实际 | PASS/FAIL |
|--------|------|------|------|-----------|
| 未 posts 直接 seal | 在 D-04 之前输入 `seal` | 显示错误："请先使用 posts 命令查看隐藏内容" | | |
| seal 后输入其他命令再 confirm | seal → 任意命令 → confirm | **不**触发结局 D（`sealPending` 应在输入其他命令后重置为 false） | | |
| 未 seal 直接 confirm | 连接后直接输入 `confirm` | 显示错误："没有待确认的操作" | | |
| seal 后换行再输入 confirm | seal → （空行） → confirm | 触发结局 D | | |

### 成功标准
- [ ] 两步确认流程完整
- [ ] `seal` 前置条件（`postsRead`）验证正确
- [ ] 错误提示清晰、符合 terminal-error 样式
- [ ] 结局 D overlay 背景深蓝黑 (#1a1a2e)，灰蓝 (#c0c0d0) 文字
