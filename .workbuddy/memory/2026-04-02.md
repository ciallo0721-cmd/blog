# 2026-04-02 工作日志

## 自毁按钮功能（admin.html）
- 在"开发选项"页新增"危险区 Danger Zone"卡片（红色边框，视觉醒目）
- 新增"启动自毁"按钮，点击后弹出专属模态框（黑红配色）
- 自毁流程：
  1. 输入 GitHub Personal Access Token（需要 `repo` 权限，提供创建链接）
  2. 输入确认词"自毁"防止误操作
  3. 通过 GitHub API `PATCH /repos/{owner}/{repo}` 将仓库设为 Private
  4. 显示成功/失败结果，失败时附带手动操作链接
- PAT 不被存储，操作后立即清除输入框内容
- ESC 键可关闭自毁模态框（已合并到统一事件监听，避免重复绑定）
- 提供备用方案：直接跳转 GitHub 仓库设置 Danger Zone 链接
