## 技术笔记

- 写入含复杂 JS/CSS 的 HTML 文件时，Write 工具或 Shell heredoc 容易因转义字符处理不当导致标签损坏
- 可靠方案：用 Python 脚本写文件（`open('/path','w', encoding='utf-8')`），避免转义问题
- 验证方法：用 Python 读取文件，regex 检查 `<\/[a-z]`（应无匹配）和 `</[a-z]`（应有匹配）
