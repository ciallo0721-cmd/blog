## file:// 协议无法加载视频（已解决）
- **问题现象**：直接双击打开 HTML 文件（file:// 协议），视频一直显示 00:00 / 00:00，无法播放
- **根本原因**：浏览器（尤其是 Chrome）对 file:// 协议有严格的安全沙箱，会阻止视频元素的加载/autoplay
- **解决方案**：用本地 HTTP 服务器访问页面（python -m http.server 或 VS Code Live Server）
- **经验**：以后测试带 video 的页面，必须用 http://localhost，不能直接 file:// 打开
