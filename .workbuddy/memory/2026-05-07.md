## articles-data.js 禁止存储文章HTML（2026-05-07 晚间）
- **问题**：各文章页面的 `updateArticleInfo` 函数中有 `contentContainer.innerHTML = articleData.content` 代码
- **风险**：即使 `articles-data.js` 现在没有 `content` 字段，但代码中有这段逻辑就是隐患
- **影响**：如果未来有人在 `articles-data.js` 中加了 `content` 字段，会把 HTML 模板的文章内容覆盖掉
- **修复**：从以下8个文件中移除了所有 `content` 替换逻辑
  1. `blog/1/index.html`
  2. `blog/2/index.html`
  3. `blog/4/index.html`
  4. `blog/6/index.html`
  5. `blog/9/index.html`
  6. `blog/11/index.html`
  7. `blog/16/index.html`
  8. `blog/muban/muban.html`（模板文件）
- **结论**：`articles-data.js` 只存储文章元数据（标题/日期/标签等），文章内容必须写在各自的 HTML 文件里
