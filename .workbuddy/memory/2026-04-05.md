## Bug 修复：后台管理系统无法进入

**问题**：从 index.html 点击后台入口输入密码后，被重定向回 index.html，无法进入 adm1n.html

**原因**：
- index.html 的后台入口只设置了 `admin_auth` 标志
- adm1n.html 的验证逻辑只检查 `verify_passed` 和 `auth_passed`，不识别 `admin_auth`

**修复内容**：
1. `index.html`：`openAdminPanel()` 函数现在同时设置 `verify_passed`、`auth_passed` 和 `admin_auth`
2. `adm1n.html`：跳转验证逻辑现在同时检查 `verify_passed`、`auth_passed` 和 `admin_auth`
3. `adm1n.html`：`initVerification()` 函数现在同时检查 `verify_passed` 和 `admin_auth`
4. `adm1n.html`：初始化验证流程现在同时检查 `verify_passed` 和 `admin_auth`
