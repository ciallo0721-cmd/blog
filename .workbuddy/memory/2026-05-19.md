## 修复 GitHub Pages Jekyll 构建错误

**问题**：GitHub Actions 构建报错 `Could not locate the included file 'mood-dashboard.html'`

**原因**：`Mood-Tracker-Dashboard/PROJECT_SUMMARY.md`（及 README.md、QUICK_START.md、docs/*.md）中包含 Liquid 语法示例（`{% include mood-dashboard.html %}`），Jekyll 将其作为真实 Liquid 指令执行，找不到对应的 `_includes/mood-dashboard.html` 文件（实际路径在 `Mood-Tracker-Dashboard/src/_includes/` 下）。

**修复方案**：创建根目录 `_config.yml`，使用 Jekyll `exclude` 配置排除整个 `Mood-Tracker-Dashboard/` 目录及其他文档文件，使 Jekyll 完全不处理这些文件。

**文件变动**：新增 `_config.yml`，已 commit & push（cad7553）。
