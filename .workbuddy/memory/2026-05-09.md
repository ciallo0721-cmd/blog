## Bug 修复：文章链接路径错误导致 /blog//blog/grayscale-test/

**问题根源**：多个页面的文章链接生成代码使用了相对路径 `article.fileName`（不带 `/blog/` 前缀），当页面本身位于子目录时，浏览器解析产生错误路径。

### 修复文件清单（共 7 个文件）

| 文件 | 问题代码 | 修复为 |
|------|----------|--------|
| `blog/16/index.html:1160` | `card.href = article.fileName` | `card.href = '/blog/' + article.fileName` |
| `blog/muban/muban.html:1079` | `card.href = article.fileName` | `card.href = '/blog/' + article.fileName` |
| `wz/index.html:1015` | `articleCard.href = article.fileName` | `articleCard.href = '../blog/' + article.fileName` |
| `blog/12/index.html:824` | `href="${adj.prev.fileName}"` (导航) | 添加 `/blog/` 前缀 |
| `blog/13/index.html:823,828,844` | 导航+相关文章均用裸 fileName | 全部添加 `/blog/` 前缀 |
| `blog/14/index.html:779,784,800` | 导航+相关文章均用裸 fileName | 全部添加 `/blog/` 前缀 |

**经验教训**：所有 blog 子目录内的页面，生成文章间链接（上下篇/相关文章）必须使用绝对路径 `/blog/` 前缀。
