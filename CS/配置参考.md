# CS 大战场 fyGrid · 配置参考（BETA 3 · 1.2km 地图 / 60 人）

> 地图 1.2km × 1.2km（对齐和平精英「度假岛」尺度），默认 30v30 共 60 人。
> 渲染目标是 **100 人（50v50）在 i3-3170 级别的 CPU 上依然流畅**。

## 一、最低 / 推荐配置

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | Intel i3-3170（2核4线程）/ 同级 AMD | i5-8400 及以上 / Ryzen 5 2600+ |
| 内存 | 4GB（浏览器标签别开太多） | 8GB+ |
| 显卡 | Intel HD 2500/4000 核显（i3-3170 自带） | GTX 1050 / Vega 8 核显及以上 |
| 浏览器 | Chrome / Edge 90+（WebGL2） | Chrome 113+ / Edge 113+（支持 WebGPU） |
| 系统 | Windows 7+ / macOS 10.14+ | Windows 10 64位+ |
| 网络 | 本地文件直开或任意静态服务器 | 同左（无联网需求，GA 统计除外） |

**最低配置下预期表现**：默认 60 人 + 自适应分辨率自动降到 0.33 渲染比例，30~45 FPS 可玩。
**推荐配置下预期表现**：?per=50（100 人）拉满，45~60 FPS。

## 二、性能机制说明（为什么低配也不卡）

1. **自适应分辨率**：每 2 秒测一次 FPS，<42 自动降渲染比例（0.5 → 0.33），>57 缓慢回升。全程自动，无需手动设置。
2. **角色 LOD**：距玩家 >180m 的角色只渲染身体（1 个 draw call），70m 内才显示头顶名字。
3. **AI 思考节流**：每个 bot 的感知+决策每 0.16~0.24s 才跑一次（带随机抖动防帧尖峰），移动/开火照常每帧。
4. **A* 二叉堆 + 内存复用**：200×200 导航格寻路，堆优化替代线性扫，缓冲区全局复用不喂 GC。
5. **静态物体免更新**：墙/柱/建筑矩阵全部静态化，不参与每帧矩阵更新。

## 四、渲染后端选项（暂停菜单内切换）

| 选项 | 本质 | 说明 |
|------|------|------|
| 自动检测 | — | 有 WebGPU 用 WebGPU，否则 WebGL |
| OpenGL系 (WebGL) | WebGL = Web 上的 OpenGL（基于 OpenGL ES 3.0） | 当前默认，支持全部自定义 GLSL 画面风格 |
| three.js 标准材质 | three.js PBR 管线 | 场景灯立体感更强，GPU 占用略高 |
| Vulkan系 (WebGPU) | WebGPU = Web 上的 Vulkan（基于 Vulkan/Metal/D3D12 模型） | 2026 年 Chrome/Firefox/Safari 26 全支持；**当前引擎文件是 three r128，未内置 WebGPURenderer，会自动回退 WebGL 并提示**。以后把 `assets/code/three.js` 换成 r167+ 版本即可直接生效 |

画面风格（仅 OpenGL系/WebGL 后端生效）：程序化马赛克 / 卡通着色 GLSL / 扫描线 CRT GLSL。
